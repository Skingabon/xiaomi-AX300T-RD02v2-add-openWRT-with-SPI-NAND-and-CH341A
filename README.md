# Xiaomi AX3000T (RD03v2) → OpenWrt: журнал попытки

Цель: поставить OpenWrt на Xiaomi AX3000T и заменить им разом VPN-роутер
(MikroTik hEX RB750Gr3) и отдельную точку доступа — расчёт был на то, что
ARM-процессор с аппаратным ускорением шифрования решит проблему низкой
скорости VPN на слабом MIPS в hEX (программное AES на MIPS без крипто-
ускорения упирается в ~10-25 Мбит/с, подробности — в соседнем репозитории
[mikrotik-hEX-RB750Gr3-add-openWRT](https://github.com/Skingabon/mikrotik-hEX-RB750Gr3-add-openWRT)).

**Статус на 2026-09-05: отложено.** Софтверный путь к root закрыт на этой
прошивке, нужен паяльник + USB-UART переходник 3.3V (заказаны, ожидаются).

## ⚠️ Главный урок: штрихкод на коробке ЛГАЛ

На коробке было написано `RD03` — вариант на **MediaTek MT7981** (ARM
Cortex-A53, есть рабочий эксплойт `xmir-patcher`, есть реальный бенчмарк
WireGuard 371 Мбит/с на этой платформе). Но сам роутер через встроенный
API честно показал другое:

```sh
curl http://192.168.31.1/cgi-bin/luci/api/xqsystem/init_info
# "hardware":"RD03v2", "model":"xiaomi.router.rd03v2", "romversion":"2.0.28 release"
```

`RD03v2` — это **совсем другая плата**: Qualcomm IPQ5018 + свитч AN8855 +
радио QCN6122, 256 МБ RAM. Разные ревизии несовместимы по прошивкам —
инструкция не под ту плату превращает роутер в кирпич.

**Правило на будущее: всегда проверять ревизию железа через этот API,
не доверять штрихкоду/коробке.**

## Софтверный root закрыт на прошивке 2.0.28 — проверено эмпирически

Прогнали [`openwrt-xiaomi/xmir-patcher`](https://github.com/openwrt-xiaomi/xmir-patcher)
(инструмент содержит встроенный portable Python в папке `python/` с уже
собранным `ssh2` — обычный `pip install -r requirements.txt` системным
Python не соберёт `ssh2-python` без MSVC Build Tools, нужно использовать
`python/python.exe` из самого репозитория).

```
$ python/python.exe connect.py 192.168.31.1
device_name = RD03V2
rom_version = 2.0.28 release
hackCheck version = 3
WARN: Exploits "arn_switch/start_binding/set_mac_filter/datacenter7" not working!!!
WARN: Exploits "Smartcontroller" are not usable (hackCheck:3)
WARN: Exploit "get_icon" not working!!! (API not founded)
```

Все три известных публичных эксплойта пропатчены Xiaomi. Видео-гайды на
YouTube (например, популярный ролик 2025 года через `xmir-patcher`)
устарели — они снимались до того, как эти дыры закрыли.

## Оставшиеся пути (по данным ADCDS)

Проект [`ADCDS/openwrt-xiaomi-ax3000t-rd03v2`](https://github.com/ADCDS/openwrt-xiaomi-ax3000t-rd03v2)
даёт чистую (mainline-based) сборку OpenWrt для этой платы:

1. **UART-пайка (основной путь, задокументирован)** — USB-UART
   переходник 3.3V, разобрать корпус, найти площадки на плате:
   *"top-left, red box"* — 3 контакта сверху вниз **Rx · Gnd · Tx**,
   115200 8N1, **3.3V** (не 5V!). UART в стоке доступен только на чтение
   (нет интерактивной консоли), проект использует его для перехвата
   загрузчика напрямую, минуя пропатченную ОС.
2. **Внешний SPI-NAND программатор (запасной, слабо задокументирован)** —
   чип флеша ESMT F50D1G41LB или Winbond W25N01KW, клипса SOIC8 на
   CH341A-программатор. Способ версионно-независимый (не зависит от
   состояния прошивки), но авторы ADCDS сами не дают по нему деталей —
   упомянут лишь как fallback "if no suitable stock image can be obtained".

Готовые `recovery.bin` образы для версии 2.0.28 у проекта ADCDS есть —
антиоткат прошивки (anti-rollback) блокером не будет.

### Важно про инструмент CH341A

Само железо (CH341A + клипса SOIC8) — универсальный USB↔SPI мост, для
NAND ограничений на уровне железа нет. Ограничение — только в штатной
программе, которая обычно идёт в комплекте с дешёвыми наборами: она
рассчитана на простые BIOS/EEPROM чипы (25xx SPI NOR, 93CXX) и **не
поддерживает SPI-NAND** (другая адресация, постраничное чтение с ECC).
Решение: ставить вместо неё бесплатный **AsProgrammer** — там есть
профили под серию Winbond W25N.

### Важно про USB-UART переходник

Нужен переходник именно на **3.3V**, не 5V. У многих дешёвых плат
(например, на CP2102) есть джампер/перемычка выбора напряжения — перед
подключением к роутеру обязательно проверить и переключить в 3.3V.
Подача 5V на 3.3V-only вход UART роутера может повредить приёмник.

## План действий, когда придут инструменты

1. Основной путь — UART, программатор не трогать без необходимости.
2. Разобрать корпус, найти площадки Rx/Gnd/Tx (см. выше).
3. Подключить переходник **крест-накрест**: TX переходника → Rx
   роутера, RX переходника → Tx роутера, GND → Gnd. Джампер переходника
   — 3.3V.
4. Следовать шагам из README `ADCDS/openwrt-xiaomi-ax3000t-rd03v2`
   (репозиторий даёт recovery.bin под 2.0.28, антиоткат не блокирует).
5. Программный эксплойт повторно не пробовать — уже подтверждено, что
   не работает на этой прошивке.

## Текущее состояние роутера

- Прошёл первичную настройку Xiaomi (привязка к Mi-аккаунту сознательно
  пропущена — не помогает получению root и не нужна для дальнейшей
  прошивки).
- IP в заводском режиме: `192.168.31.1`.
- Пароль веб-интерфейса задан локально при первичной настройке (не
  публикуется здесь).
